# Лабораторная работа: агентский театр

## Задание

Реализовать многоагентную систему для автоматического написания (симуляции) пьесы. Основная логика работы - это наличие нескольких различных LLM, промптированных определённым образом, и симуляция их диалога друг с другом.

Важно получить в итоге осмысленный диалог, раскрывающий какую-то тему, с героями, имеющими свои особенности речи, взгляды на мир и т.д. Этого можно добиться как за счет промптирования, так и за счет дополнительного перефразирования реплик, использования Few-Shot Learning и т.д. 

## Отчёт

Код работы помещается в файл LLM_Theatre.ipynb, с пояснительными комментариями по принципам реализации. Отчёт по работе оформляется в [REPORT.md](REPORT.md) на основе заданного там шаблона.

## Оценивание

Работа оценивается по баллам в 10-балльной системе:

* Минимальная реализация - **осмысленный** диалог двух LLM между собой [2 балла]
* Осмысленное подключение к агенту инструментов, в т.ч. файлового поиска [+1 балл] 
* Оригинальность работы, крутизна финального материала, необычность и самобытность - [+0-3 балла]
* Один из персонажей основан на выполняемой локально OpenWeight-модели c HuggingFace [+1 балл]
* Диалог между 3 и более персонажами [+1 балл] - необходимо **придумать механизм** определения того, чья реплика будет следующей (классификатор, отдельная LLM, высказывается каждый с последующим голосованием и т.д.)
* Макропланирование сюжета [+1 балл] - заранее GPT пишет общий сюжет пьесы, который затем раскрывается в нескольких действиях
* Закадровые комментарии [+1 балл] - описываются сцены, уточнения к репликам (*шепотом*, ...), действия актёров (*проходит к столу*, ...)
* Синтез получившегося диалога голосом [+1 балл] - по возможности используйте качественный синтез локальными моделями (Suno Bark, на основе образцов своего голоса) или elevenlabs. Простой синтез Yandex Speechkit - 0.5 балла. 


Важнейшими элементами оценки являются:

* **Мотивирующий абзац** (*Project Statement*) - кратко описывает, чем ваша работа оригинальна, отличается от простейшей реализации, почему преподавателю стоит на неё внимательно и с интересом посмотреть.
* **Выводы** - чему вы научились, какие уроки для себя извлекли.

## Реализация: «Поправка к протоколу»

Два сотрудника контрразведки, Орлов и Волкова, проверяют показания инженера Соколова. У них разные манеры разговора и отдельная память. Исходные ответы Соколова пишет локальная Qwen3-1.7B, затем их обрабатывает облачный редактор речи. Сотрудники, режиссёр, редактор и планировщик работают через DeepSeek V4.1 Flash в Yandex AI Studio. В журнале сохранены исходные и итоговые реплики. Дело и персонажи вымышлены.

1. Установите Python 3.10+ и зависимости: `python -m pip install -r requirements.txt`.
2. Скопируйте `.env.sample` в `.env` и заполните `api_key` и `folder_id`. Если `.env` отсутствует, notebook читает `.env.m1`. Существующие переменные окружения имеют приоритет.
3. Откройте `LLM_Theatre.ipynb` в Jupyter или VS Code, выберите установленное окружение Python и выполните все ячейки. Альтернатива: `python scripts/run_notebook.py` — он также сохраняет настоящие выводы ячеек.
4. Готовая пьеса появится в `results/play.md`, подробный журнал — в `results/run.json`.

Выполненный прогон уже сохранён: 3 действия, 22 реплики. Для чтения есть [вычитанная версия сцены](results/play_edited.md), подготовленная Codex после генерации; исходный модельный текст и измерения сохранены отдельно. Повторный запуск обновляет модельный результат, а вычитанная версия относится к прогону от 11 ноября 2026 года.

После каждой реплики сохраняется `results/checkpoint.json`, включая личную память персонажей. Если прогон прервался, запустите `python scripts/run_notebook.py --resume`: уже написанные действия повторно не генерируются. Для новой пьесы запускайте без `--resume`.

Первый запуск скачивает около 3,5 ГБ весов в `.model-cache`, после чего Qwen генерирует реплики на компьютере. На CPU нужно около 7 ГБ для весов плюс память для вычислений; GPU необязателен. На GPU с аппаратной поддержкой bfloat16 и минимум 6 ГБ видеопамяти применяется bfloat16, иначе используется CPU и float32. На GTX 1650 здесь выбран CPU. Сеть нужна для первоначальной загрузки и облачных запросов; обращения к Yandex AI Studio расходуют квоту аккаунта. Синтез речи исключён.

Проверка логики без сети и скачивания весов: `python scripts/check_notebook.py`. Она использует тестовые ответы, не выдаёт их за сгенерированную пьесу и не перезаписывает результаты. Короткая проверка облачного доступа: `python scripts/run_notebook.py --smoke-cloud`.

В текущем окружении Python установлен, но команда `python` отсутствует в PATH. Здесь генератор можно запустить из PowerShell так:

```powershell
& "$env:LOCALAPPDATA\Programs\Python\Python312\python.exe" scripts/run_notebook.py
```
